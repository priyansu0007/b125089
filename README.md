## 🚀 How to Compile and Run

### For C Programs (Lab 1)

```bash
# Navigate to the lab folder
cd "lab 1"

# Compile
gcc q1.c -o q1

# Run
./q1
```

### For C++ Programs (Lab 2 and onwards)

```bash
# Navigate to the lab folder
cd lab_2

# Compile
g++ q1.cpp -o q1

# Run
./q1
```
